## Gestion des Packages
Vous avez donc `paru` installé, c'est un wrapper de `pacman`, le package manager par défaut d'Arch Linux.

Pour update le système : `paru` suffit, il updatera les repositories, vous proposera de mettre à jour les packages des repos officielles si besoin et ensuite vous proposera pour les packages de L'Arch User Repository (AUR).

Pour installer de nouveaux packages : `paru -S <package>`, il ira voir d'abord dans les repos officielles puis dans l'AUR s'il n'y est pas et vous proposera l'installation.

Pour supprimer des packages : `paru -R <package>`.

## Raccourcis essentiels pour l'utilisation du Desktop Environment
La touche SUPER est la touche Windows / équivalent.

- `SUPER + R` -> ouvre le sélecteur d'application
- `SUPER + C` -> ferme l'application en cours d'utilisation
- `SUPER + 1-9` -> va au workspace 1-9
- `SUPER + SHIFT + 1-9` -> bouge l'application en cours d'utilisation dans le workspace 1-9
- `SUPER + SHIFT + S` -> ouvre l'utilitaire pour screen
- `SUPER + Q` -> ouvre un terminal
- `SUPER + M` -> verrouille le PC
- `SUPER + E` -> ouvre le file manager
- `SUPER + V` -> toggle le mode flottant pour la fenêtre en cours d'utilisation
